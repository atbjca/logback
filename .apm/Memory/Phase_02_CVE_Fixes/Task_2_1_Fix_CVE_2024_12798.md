# Task Log: Task 2.1 - 修复 CVE-2024-12798（JaninoEventEvaluator ACE）

## Summary
Removed all JaninoEventEvaluator classes from logback-core, logback-classic, and logback-access to eliminate the arbitrary code execution vulnerability (CVE-2024-12798). Commit: `f5dabd9fc`.

## Details
- Followed official 1.3.x fix (commits `c17e58838` + `b44b940cc`) adapted to 1.2.x architecture
- Deleted 3 source files and 3 test files (816 lines removed)
- Modified 8 additional files to clean up all references
- Key architectural difference from 1.3.x: in 1.2.x the class is `EvaluatorAction` extending `AbstractEventEvaluatorAction` (vs `ClassicEvaluatorAction` extending `EventEvaluatorAction` in 1.3.x)
- Changed `defaultClassName()` in both classic and access `EvaluatorAction` to return `null` (will log error if `<evaluator>` used without explicit class)
